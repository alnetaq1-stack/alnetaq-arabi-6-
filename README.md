# موقع النطاق العربي 6 — مركز متخصص في موبار

موقع عربي RTL متجاوب مبني بـ HTML وCSS وJavaScript، وجاهز للنشر على GitHub Pages.

## قبل النشر
- رقم واتساب المركز مضبوط مسبقاً: `966532921615`.
- موقع المركز المعروض: صناعية العاصمة – مخرج 28 – الرياض.
- العلامات المعروضة: Dodge وChrysler وJeep وRAM وSRT.
- صورة الهيرو الحالية صورة خارجية تجريبية من Unsplash؛ استبدلها بصورة حقيقية للمركز أو إحدى سياراته عند توفرها.

## النشر على GitHub Pages
1. أنشئ مستودعاً عاماً جديداً باسم تختاره.
2. ارفع الملفات الثلاثة `index.html`, `styles.css`, `script.js` إلى جذر المستودع.
3. افتح Settings > Pages.
4. اختر Deploy from a branch ثم `main` و`/(root)` ثم Save.
5. انتظر اكتمال النشر وافتح الرابط الذي يظهر في صفحة Pages.

- نموذج الحجز يفتح واتساب برسالة جاهزة، ولا يرسلها تلقائياً.
- لا توجد حالياً قاعدة بيانات لحفظ الحجوزات؛ تصل الرسائل عبر واتساب بعد أن يرسلها العميل.
